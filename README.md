# 🎬 IMovies — Full-Stack MERN Cinema Reservation Platform

Refer to the root [README.md](../README.md) for full project documentation, architectural overview, and 1-click launchers.

## Quick Commands
- **Seed Database**: `npm run seed` (inside `server`)
- **Start Backend**: `npm run dev` (inside `server`)
- **Start Frontend**: `npm run dev` (inside `client`)
- **1-Click Launch**: Double-click `run-all.bat` in the project root.
